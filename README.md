# Chatbot-for-Internship-Support
This offline assistant utilizes TF-IDF vectorization and Cosine Similarity to provide instant, automated responses to internship-related FAQs without requiring external API calls. It features a Gradio-based interface that maps user intent to a curated knowledge base, offering a reliable and private support tool for candidate inquiries.
This Internship Guidance Navigator is a high-efficiency, offline communication tool designed to provide instantaneous support for candidate inquiries. Unlike traditional chatbots that rely on expensive cloud-based Large Language Models (LLMs) or constant internet connectivity, this system utilizes a specialized Natural Language Processing (NLP) pipeline built on the Scikit-Learn framework. By leveraging TF-IDF (Term Frequency-Inverse Document Frequency) vectorization, the engine converts the curated knowledge base into a mathematical "vector space," allowing it to interpret the importance of specific terms within a user's question relative to the available FAQ data.

The core intelligence of the chatbot is driven by a Cosine Similarity algorithm, which calculates the angular distance between the user’s vectorized query and the pre-indexed knowledge registry. This approach enables the bot to understand "semantic intent" rather than relying on simple, rigid keyword matching. When a user asks a question, the system identifies the closest logical match within the database and returns a structured response. If the confidence score falls below a specific threshold, the bot intelligently shifts to a fallback intent mapping system, providing the user with a categorized menu of topics to ensure they are never left without guidance.

For the user interface, the script integrates the Gradio library, creating a modern, web-accessible dashboard that can be launched locally or shared via a public URL. The interface includes a real-time chat log, suggested example questions to lower the barrier for user interaction, and a professional "Monochrome" aesthetic suitable for corporate environments. Because the entire processing loop—from tokenization to similarity scoring—happens locally on the host machine, the system offers near-zero latency and total data privacy, as no conversation data ever leaves the local environment.

To ensure a "human-like" interaction flow, the bot includes a pre-processing layer that utilizes Regular Expressions (Regex) and TextBlob for string normalization. This layer cleans the input by removing noise and standardizing casing, ensuring that typos or varied punctuation do not interfere with the matching logic. The result is a robust, "zero-maintenance" support tool that provides 24/7 assistance on complex topics such as application protocols, eligibility standards, and financial benefits, significantly reducing the manual workload for HR and recruitment teams.
